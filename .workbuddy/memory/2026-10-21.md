# 2026-10-21

## 新增 AI 图生图（I2I）功能

基于 https://docs.cloudbase.net/ai/image-model/wx-server-sdk 的图生图能力，模型 `HY-Image-v3.0-I2I-ToB-v1.0.1`。

**新增**
- `cloudfunctions/imageToImage/index.js` + `package.json`（wx-server-sdk 4.0.2）
  - 垫图入口优先级：`imageUrls`（公网 URL）> `fileID`（云存储，内部用 getTempFileURL 换临时链接）> `images`（base64）
  - 校验：prompt 必填且 ≤500 字、垫图最多 1 张、≤10MB、仅 jpg/jpeg/png
  - 生成结果下载后 `cloud.uploadFile` 转存到 `ai-images/i2i/`，返回 `fileID`（永久）+ `url`（24h 兜底）+ `revisedPrompt`
  - 云函数 timeout 设 150s；控制台侧需把云函数超时改成 900s
- `pages/aiImage/` 分包页面（js/json/wxml/less）：选图 → 上传云存储 → 提示词（含 5 个预设）→ 生成 → 结果预览/保存相册/复制 fileID/用于发布（eventBus 事件 `ai-image-generated`）

**修改**
- `app.js`：`initCloud()`，wx.cloud.init（env 取 config.cloudEnv，try/catch 保护）
- `config.js`：新增 `cloudEnv`
- `app.json`：新增 `pages/aiImage` 分包
- `pages/my/index.js`：settingList 增加「AI 图生图」入口（url `/pages/aiImage/index`，t-cell 自带 jumpLink）
- `project.config.json`：`cloudfunctionRoot: "cloudfunctions/"` + aiImage 编译条件
- `.eslintignore`：忽略 `cloudfunctions`（CommonJS，不适用小程序端 lint 规则）

**踩坑记录**
- 垫图不能直传 base64 走 callFunction（入参体积上限 + 10MB 限制），必须先 `wx.cloud.uploadFile` 换 fileID
- t-tag 没有 `content` 属性，内容走 slot；`t-tag` 的 click 事件取 dataset 不稳，改用外层 view 包 `bindtap`
- 保存到相册优先用 `wx.cloud.downloadFile(fileID)`，避免官方临时 URL 未进 downloadFile 域名白名单

## 复核修正（同日）

复查后修掉 7 处问题：
1. `app.js` 的 `App({` 被前次编辑误加缩进 → 已还原
2. `wx.cloud.init({ env: config.cloudEnv || undefined })` → 改为条件展开，避免传 `env: undefined` 的兼容风险
3. 删除 `useForRelease`（发布页并未监听 `ai-image-generated`，是死代码），替换为 `resetResult`（清空结果、保留垫图与提示词便于微调）
4. toast 与 `wx.showLoading` 重叠 → 改为 finally 里先 `hideLoading` 再弹 toast（用 `succeeded` 标记）
5. 云函数 `downloadImage` 只认 https → 兼容 http/https
6. 云函数 `images` 传了 `data:image/jpeg;base64,` 前缀 → 按文档改为裸 base64
7. `fileIdToUrl` 报错把内部 fileID 透给前端 → 改通用文案 + console.error

**已核实有效**（不用动）：
- `t-button` 的 `t-class` 是 externalClasses 成员，可用；`t-cell` 的 `jumpType` 默认 `navigateTo`，`url` 跳分包正常
- TDesign 组件均 `styleIsolation: apply-shared`，页面 less 里的 `t-class` 外部样式能生效
- `wx.previewImage` / `<image>` 支持 `cloud://` fileID（基础库 3.7.8）

**待办（配置侧，非代码）**：开通云开发 → `config.js` 填 `cloudEnv` → 部署云函数（云端装依赖）→ 控制台超时改 900s → 后台配「用户隐私保护指引」（相册/摄像头/选取照片）→ 确认生图资源可用

- `pages/home/index.wxml`：把原 `.home-release` 单按钮容器改为 `.home-fab` 垂直堆叠容器，上面新增 `AI 生图`（theme=light）+ 下面保留 `发布`（theme=primary）

- `pages/home/index.js`：新增 `goAiImage()`
