API Landscape Review · 中国内地

国内图片生成 API 调研

面向「上传人像 → 风格化 / 写真」这类小程序场景，横评字节、阿里、腾讯、智谱、硅基流动、百度六家的在售生图接口：能力、单价、接入方式与合规门槛。所有价格为 2026 年 10 月公开口径，以各厂商控制台为准。

调研时间：2026-10-18 价格单位：人民币 / 张 选取口径：境内主体可直接实名开通、支持商用

一、先给结论

如果今天就要为 ai-photo-miniapp 选一家主供应商，我的判断是：主用火山方舟 Seedream，备用阿里百炼 Qwen-Image，腾讯混元作为第三家做容灾。理由不是"谁最强"，而是三件事同时成立：图生图/参考图能力够用、单张价格在 0.12–0.25 元区间、接入是标准 HTTP 同步接口。

4. 智谱 · GLM-Image / CogView-4 — 便宜，但主打文生图

GLM-Image 0.1 元/次，原生 1024–2048 任意比例，中文文字渲染是其核心卖点（厂商口径的中文长文本准确率很高），支持指令编辑；CogView-4 0.06 元/次，以文生图为主，人像一致性和参考图能力弱，更适合配图而非写真。适合"图里要有大量中文"的海报/信息图，不适合本项目主线。

5. 硅基流动 · 一个 Key 横跳多家 — 最适合做原型与压测

  • Kwai-Kolors/Kolors — 免费，文生图，配图级质量
  • Tongyi-MAI/Z-Image-Turbo — 0.1 元/张，几秒出图，Z-Image 全量版 0.3 元/张
  • Qwen/Qwen-Image-Edit-2509 — 0.3 元/张，多图编辑、风格迁移、换背景、虚拟试穿
  • 新用户赠 16 元体验金，OpenAI 兼容 /v1/images/generations

它的价值不在便宜，而在接口统一：同一份代码换 model 字段就能对比五六家模型的效果，做提示词 A/B 时非常省事。缺点是转售层，SLA、限流、模型上下架都不由你控制，不建议作为唯一生产源。

6. 百度 · 文心一格 — 不建议新项目使用

API 按"点"计费，基础尺寸 v1 每张 2 点、v2 每张 3 点，高级尺寸 4–6 点，20 万点大包折合约 0.14 元/点，折算下来单张 0.28–0.84 元，价格高于同类且迭代节奏慢；胜在国风/水墨题材与版权登记体系（每张带商用证书），政务、文旅类项目仍有价值。新用户约 100 次免费绘图额度。对"人像风格化"这个需求，它的参考图与人脸保持能力不是强项。

四、按场景选型

人像风格化 / 写真（本项目）

  • 首选：Seedream 5.0 Flash（0.12，10 张参考图，图生图）
  • 质量位：Seedream 5.0 Pro / Qwen-Image 3.0 Pro
  • 垂直位：腾讯 AI 写真免训练模式（人脸保持最稳，但并发贵）
  • 避开：CogView-4、文心一格（一致性与参考图弱）

中文海报 / 信息图（图里要写字）

  • 首选：GLM-Image（0.1）、Qwen-Image 3.0（0.18）
  • Qwen-Image-Edit 能在保留原字体的前提下改图内文字，做多语言物料很好用
  • Seedream 5.0 系列的中文小字也已"不乱码"，但复杂信息图仍会出错

电商主图 / 商品换背景

  • 首选：Seedream 5.0 Flash 多图融合（商品图 + 场景图）
  • 备选 Qwen-Image-Edit-2509（0.3，硅基流动）、腾讯"商品背景生成"专用接口
  • 要矢量/品牌规范：Recraft 系（海外，不适用境内合规）

批量配图 / 内部工具

  • 首选：Kolors（免费）、Z-Image-Turbo（0.1）
  • 几千张级别用智谱 CogView-4（0.06）走批量接口还能再打折
  • 量大到百万级再考虑自建 Z-Image / Qwen-Image 开源权重

三条通用工程结论：
① 永远不要在小程序端直连模型 API——密钥会泄漏，域名也过不了审核。必须经云函数/自建后端中转，这个项目已有的"创建任务 → 轮询"抽象正好合适。
② 产物 URL 一定会过期（万相 24h、其他多为临时地址）。拿到图立刻转存到 COS/OSS 并绑 CDN，再返回自己的永久地址，否则用户历史记录里全是裂图。
③ 输入图也要转存并压缩。参考图按长边 1280 压到 1MB 以内，既省钱又快；原图另存一份供"高清重绘"用。

七、合规：这是比价格更硬的门槛

小程序做 AI 生图，不是"接个 API 就能上线"。微信把 AI 审核拆成"先类目、后代码"两道关，类目没过代码包 100% 驳回。

  1. 服务类目：必须申请「深度合成 → AI 绘画」（涉及换脸还要 AI 换脸子类目）。仅向企业/组织主体开放，个人主体做不了。材料齐全 1–2 个工作日，最长 7 个工作日。
  2. 资质二选一：
    • 自研：主体自己的《互联网信息服务算法备案》（生成合成类），周期 2–4 个月；
    • 用第三方技术：技术方的算法备案截图（须为"生成合成类"）+ 双方盖章合作协议（写明 AppID、算法名称、备案编号、使用场景）+ 在用证明。
  3. 走微信云开发最省事：云开发 AI 模块可直接生成《深度合成算法合作协议》与备案截图（主体需一致、环境有效期 ≥3 个月），这也是这个项目当前技术栈的天然优势——cloudfunctions/ 已经在用云开发了。
  4. AI 标识是头号驳回原因：所有生成内容需显著标注"AI 生成"，《人工智能生成合成内容标识办法》（2025-09-01 施行）要求显式标识 + 隐式标识（文件元数据）。做法：结果图右下角烧角标 + 页面常驻提示 + 下载文件写入元数据。
  5. 内容审核要双向：用户上传的人像先过一遍（涉黄涉政涉暴），生成结果再过一遍再返回。国内云厂商的图片内容安全接口约 1–2 元/千次，别省这笔钱。
  6. 人脸是敏感个人信息：需要单独同意、明示用途与保存期限、提供删除入口。若做"训练专属写真模型"，还要说明模型有效期与销毁机制（腾讯 AI 写真模型默认 1 年有效）。严禁生成他人肖像，需要活体/实名校验的场合不能省。
顺序建议：先用个人账号 + 硅基流动跑通产品验证 → 注册企业主体 → 申请深度合成类目（用云开发的合作协议+备案材料）→ 接火山方舟做生产。别在类目没过之前就买大额资源包。

八、落到本项目的接入建议

现有 services/generation.js 已经把"上传 → 创建任务 → 轮询 → 拿到图片 URL"抽象好了，接哪家都不用改前端。建议只在后端加一层 provider 适配：

// cloudfunctions/quickstartFunctions/providers/index.js
const providers = {
  seedream: require('./seedream'),   // 火山方舟，主
  qwen:     require('./qwen'),       // 百炼，备
  silicon:  require('./silicon')     // 硅基流动，原型/降级
}

// 统一契约，前端无感切换
// createTask({ imageUrl, prompt, ratio, count }) -> { providerJobId }
// queryTask(providerJobId) -> { status: 'processing'|'done'|'failed', images:[], progress }
// 失败自动 fallback 到下一家，并落一条审计日志

const CHAIN = ['seedream', 'qwen', 'silicon']  // 按成本/质量排序
  • 模型分层：普通档 doubao-seedream-5-0-flash-260915（0.12）；"高清重绘"档 doubao-seedream-5-0-pro-260628（0.30/0.60）。用一个 quality 字段切换，不必两套代码。
  • 提示词模板放服务端：风格（电影感/胶片/国风/水彩/证件照）各存一条固定前缀，用户只填 200 字以内的补充描述。模板迭代不需要发版小程序。
  • 结果转存：拿到第三方 URL 后立刻上传云存储，写库只存自己的 fileID；第三方 URL 只做临时中转，绝不返回给前端。
  • 幂等与限流：同一用户 60 秒内只允许 1 个进行中任务；单任务最多重试 2 次，避免"用户狂点 + 模型重试"双倍烧钱。
  • 成本埋点：每次调用记录 provider / model / 张数 / 是否失败 / 耗时，一周就能算出各家的真实单均成本与成功率——这比任何横评文章都准。
