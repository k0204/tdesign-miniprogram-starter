**六个能直接改变出图结果的结论：**

1. **平视视角占七成**。整库的语法是「贴身观察」，不是炫技角度。俯拍（13%）集中在建筑与航拍，仰拍（8%）集中在城市与街头——想做出差异，先动机位。
2. **全景 39% 远多于特写 6%**。场景承载的信息量被刻意保留，人是环境里的一个元素，而不是脸部的特写。写提示词时要先交代环境，再落人物。
3. **中心构图 40%，三分法只有 10%**。三分法在这批成片里被严重高估；稳定的配方是「人物居中 / 主体压在画面纵深轴上」，留白与对称各占 8%、7%，用于安静与秩序感。
4. **柔光 + 散射合计 69%**。硬光只有 21%，逆光 17%——**逆光是氛围感的主开关**，黄金时刻 10% 是它的加强版。想加情绪，优先加逆光边缘光，而不是加饱和度。
5. **低饱和（18%）+ 颗粒（35%）是后期主旋律**；色调上被判为高饱和的只有 1.7%，但后期维度里「提了饱和」的有 13%（集中在风光与航拍）。颜色上蓝（38%）、白（37%）、绿（33%）、灰（31%）四色撑起大半画面，暖调略多于冷调（43% vs 40%）。
6. **情绪词高度收敛**：疏离、静谧、清冷、安静、孤独、怀旧是一族；温柔、慵懒、松弛、日常、温暖是另一族。这两族审美的写法不同——前者靠留白、低饱和、背影或侧脸；后者靠柔光、浅景深、生活化道具。

## 二、可复用的提示词骨架

从 803 条提示词里归纳出的稳定结构，按此顺序组织，出图还原度最高：

```
【景别 + 机位视角】+ 【场景/环境与时间】+ 【主体：性别年龄 + 造型 + 服装】
+ 【姿势 + 表情视线】+ 【道具 / 前景层次】+ 【光线：方向 + 性质 + 时段】
+ 【构图结构】+ 【色调 + 后期质感】+ 【情绪落点】
```

- **前 20 个字决定构图**：景别、机位、画幅要最先说，模型对开头最敏感。
- **光线要写方向和性质两个词**（如「侧逆光 + 柔光 + 傍晚」），只写「打了光」没有用。
- **后期质感是风格开关**：颗粒、褪色、低饱和、青橙偏色，写上就能把「普通照片」推成「胶片感」。
- **情绪放最后**：给一个 1—2 词的落点（疏离 / 慵懒 / 辽阔），模型会用它调整整体调性。

## 四、方法与口径

- **逐张分析**：803 张全部经视觉模型单张读取，非抽样、非拼图；单张打不开的也保留记录。
- **18 维定义**：场景（环境与时间）、姿势、表情视线、造型（发型妆容配饰）、服装、道具、机位（高度+方向+距离）、焦段、景别、景深、光线（方向+性质+时段）、构图、前景、色调、后期、情绪、叙事，以及 `prompt` 成品提示词。
- **焦段口径**：有 EXIF 的用真实毫米数（470 张），没有的按透视与压缩感判为广角 / 标准 / 中长焦 / 长焦压缩，不编造毫米数。
- **提示词口径**：70—110 字中文，按「景别机位 → 场景 → 主体造型 → 姿势表情 → 光线 → 构图 → 色调后期 → 情绪」的顺序组织，可直接投喂文生图模型。
- **统计口径**：维度取值按关键词归一化后统计，一张图可命中多个标签，故各维度百分比不必相加为 100%。
