这批图不是拿来「看」的，是拿来「抄配方」的。所以每一张都拆到可复现的颗粒度：机位多高、光从哪来、什么景别、什么后期，最后压成一条 70—110 字的提示词。下面是从 803 张里量化出来的共性，以及 12 个风格各自的写法。

01六个能直接改变出图结果的结论

  1. 平视占 72%。整库的语法是「贴身观察」，不是炫技角度。俯拍 13% 集中在建筑与航拍，仰拍 8% 集中在城市与街头——想做出差异，先动机位。
  2. 全景 39%，特写只有 6%。场景承载的信息量被刻意保留，人只是环境里的一个元素。写提示词要先交代环境，再落人物。
  3. 中心构图 40%，三分法只有 10%。三分法在这批成片里被严重高估；稳定配方是「主体居中 / 压在纵深轴上」，留白 8%、对称 7% 用来做安静与秩序。
  4. 柔光 + 散射合计 69%，硬光只有 21%，逆光 17%——逆光是氛围感的主开关，黄金时刻是它的加强版。想加情绪，加逆光边缘光，别加饱和度。
  5. 颗粒 34% + 低饱和 18%，高饱和仅 12.8%。颜色靠蓝 38%、白 37%、绿 33%、灰 31% 撑起大半画面，暖调略多于冷调。
  6. 情绪词高度收敛成两族：疏离 / 静谧 / 清冷 / 孤独 / 怀旧是一族，靠留白、低饱和、背影侧脸；温柔 / 慵懒 / 松弛 / 日常 / 温暖是另一族，靠柔光、浅景深、生活化道具。选错族，色调再准也不像。

03可复用的提示词骨架

从 803 条提示词里归纳出的稳定结构，按这个顺序组织，出图还原度最高：

【景别 + 机位视角】+【场景 / 环境与时间】+【主体：性别年龄 + 造型 + 服装】
+【姿势 + 表情视线】+【道具 / 前景层次】+【光线：方向 + 性质 + 时段】
+【构图结构】+【色调 + 后期质感】+【情绪落点】
  • 前 20 个字决定构图：景别、机位、画幅最先说，模型对开头最敏感。
  • 光线写两个词：「侧逆光 + 柔光 + 傍晚」。只写「打了光」没有用。
  • 后期质感是风格开关：颗粒、褪色、低饱和、青橙偏色，写上就能把普通照片推成胶片感。
  • 情绪放最后：一个 1—2 词的落点（疏离 / 慵懒 / 辽阔），模型会用它调整整体调性。

0412 个风格的要素配方

每张卡片里的「骨架」取的是该风格相对全库更突出的取值，不是出现最多的那个——所以 12 张卡片彼此能拉开差异，而不是都写着「平视 + 柔光 + 中心构图」。

人像写真  晓港漫步的百合花少女
南方老城巷弄的街边棋牌摊，麻将桌、电动车与蓝色遮阳伞环绕，一位扎黑长直双马尾的少女穿白衬衫与浅灰半身裙，背靠树干抱臂站立，神情平静疏离直视镜头；侧逆柔光，胶片颗粒低饱和灰绿调，居中构图，安静而格格不入。
日系胶片  日系人像
夏日午后的公园，一名穿白衬衫蓝格裙的少女盘腿坐在大树下弹木吉他，低头浅笑，黑长发低扎，侧逆柔光从树梢洒下，草绿背景轻微虚化，人物居中偏右、树干作竖线分割画面，低反差颗粒胶片，草绿米白暖调，安静松弛的青春气息。
情绪氛围  小众婚纱胶片
暗色室内，二十岁女子头戴白色蕾丝头纱、垂下珍珠链坠、正红唇带雀斑，穿白色蕾丝婚纱正面静立微低头，抬眼看镜头，一支燃烧的蜡烛在画面右侧前景虚化成暖黄光团，暗棕与暖黄的低调，重颗粒暗部浓重，神秘带仪式感。

方法

  • 逐张分析，不抽样：803 张全部单张读取视觉模型，过程禁止拼图；分析按 18 份切片并行，主流程只做合并与校验（缺漏 0 / 重复 0 / 空字段 0）。
  • 18 维定义：场景（环境与时间）、主体、姿势、表情视线、造型（发型妆容配饰）、服装、道具、机位（高度 + 方向 + 距离）、焦段、景别、景深、光线（方向 + 性质 + 时段）、构图、前景、色调、后期、情绪、叙事。
  • 焦段口径：有 EXIF 用真实毫米数，没有的按透视与压缩感判为广角 / 标准 / 中长焦 / 长焦压缩，不编造毫米数。
  • 提示词口径：70—110 字中文，按第 03 节的顺序组织，可直接投喂文生图模型。
