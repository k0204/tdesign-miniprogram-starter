## 三、组合公式

```
[镜头包] + [场景包] + [人物包] + [风格包] + [叙事包]
```

渲染顺序固定，不能调换：

```
【景别 + 机位】→【环境 + 天气 + 前景】→【主体 + 造型 + 服装 + 姿势 + 表情 + 视线 + 道具】
→【光位 + 光质 + 色温 + 色调 + 后期】→【情绪 / 叙事】
```

两条硬规则（来自 803 条成片归纳）：

- **前 20 个字决定构图**：景别与机位必须最先说，模型对开头最敏感。
- **情绪放最后**，给 1–2 个词的落点，它会调整整张图的调性。

## 五、怎么用

### 用法一：选包拼装（最常用）

```
[lens-03 远景] + [scene-03 山峦之间] + [人物: 女性·青年·单人·站立·凝视远方] + [style-06 暗调浓郁] + [story-05 自然秩序与光线层次]
```

拼出来：

> 大场景构图，平视机位，大景深，环境清晰，三分法构图，竖幅构图，山峦之间，环境细节清晰，信息层次丰富，一位年轻女性，自然发型与淡妆，站立，神情沉静，凝视远方，顺光，自然柔光，暖色温，暖色调，偏橙黄，色彩浓郁，暗调压缩，阴影厚重，自然秩序与光线层次

### 用法二：只换风格包（同一主体，不同成片）

固定 `lens-01 + scene-01 + 一位年轻女性·自然放松的姿态`，依次换 14 个风格包，就得到 14 张风格各异的成片。这是最省力的复用方式。

### 用法三：只换场景包（同一风格，不同外景）

固定 `style-01 暖调胶片 + lens-02 中景`，换 12 个场景包，就得到 12 张「同一套调子的不同外景」。

### 用法四：当风格前缀用

只取风格包的短语，接在任意自己的提示词前面：

```
右侧光，自然柔光，暖色温，暖色调，偏橙黄，自然饱和，暖调胶片质感，温暖柔和，<你自己的画面描述>
```

## 六、整理过程中修掉的问题

这些不是洁癖，是不修就会让库自相矛盾的地方。全部有数据证据。

### 6.1 「风格」字段同名不同义

A 库 25 个值是**题材**（女性肖像摄影 183 / 儿童人像摄影 137），B 库 12 个值是**流派**（日系胶片 61 / 古风国风 62）。直接合并时，检索「日系」在 A 库 0 命中。

**修法**：拆成 `subjectGenre`（题材）与 `school`（流派）两个正交字段。

### 6.2 A 库「分组」里混了两套体系

`bulk/01_portrait`～`bulk/12_lifestyle` 是**题材**；`01_natural-light`～`14_male-portrait` 是**风格**。同一个字段里两种语义。

**修法**：按前缀分别路由到 `subjectGenre` 与 `school`。

### 6.3 情绪维度塌陷

B 库 702/803 = **87%** 是「自然真实」，A 库 527/1450 = 36%。这一维几乎没有区分度。

**修法**：保留但降低权重，并在组合里只用 `mood` 的次级值（温柔/安静/复古等）。

### 6.4 焦段与景别不联动

| 面部特写 | 207 | **194（94%）** |
| 中景 | 561 | 136（24%） |
| 全景 | 1111 | 1007（91%） |

人像特写用广角会透视畸变，摄影上不成立。而「中长焦」全库只有 51 条，且没有一条落在特写上。

**修法**：`lens` 维度**不进组合库**，只留在原始记录里备查。

### 6.5 占位符污染统计

以下取值是标注时的默认填充，不是真实信息，当作正常值参与统计会把所有组合都拉向它：

| 维度 | 占位符 | 占比 |
|---|---|---|
| `scene` | 环境细节丰富的场景中 | 61.3% |
| `pose` | 自然放松的姿态 | 77% |
| `gaze` | 自然视线 | 93% |
| `expression` | 自然平和 | 59% |
| `composition` | 中心构图 | 81% |

**修法**：统一标记为 `generic`，组合库统计时剔除。这是场景包覆盖率只有 38% 的原因，也是它可信的原因。

### 6.6 B 库「构图手法」是四维粘连的复合串

`环境人像构图，主体居中，大景深，环境清晰，竖幅构图` —— 一个字段里塞了景别、主体位置、景深、画幅。53 个取值几乎两两不等，跨库比较恒为 0。

**修法**：拆成 `shot` / `composition` / `dof` / `frame` 四个正交维。

### 6.7 黑白混在「光线性质」里

B 库 116 条 `光线性质` = 「黑白光影」。黑白是影调不是光型，混在光线里会让「黑白」这个风格包检索不到。

**修法**：单独记为 `lightQuality=mono`，同时进 `tone` / `colorTemp` 的 `mono`。

### 6.8 服装字段 92% 为空

A 库 1450 条里 **1331 条（92%）** `服装` 是 `—`。这会影响复原出的提示词——全身构图时模型会自己脑补着装。

**修法**：数据层不补（会失真）；出图侧追加「人物着装完整得体」兜底。

## 八、已知局限

1. **A 库维度塌陷严重**：机位 99% 平视、构图 81% 中心、景深 97% 大景深。这三个维度组合空间名义上有 5×5×3，实际取不到那么多种。真正有区分度的只有光位、光质、色调、后期、影调五个。
2. **B 库 48%（385 条）是无人物的场景图**，人物包对它们全为空。做「人像配方」时应按 `category=portrait` 过滤。
3. **流派 1354 条是推导值**（`schoolSource=derived`），只有 899 条是显式标签。推导值可信度低一档。
4. **叙事包 story-01 占 35.7%**，本质仍是低信息量项，拼装时可省略。
